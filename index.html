Un frontend sencillo publicado desde una infraestructura propia con Ubuntu Server, Docker y Coolify.

Coolify administra el recorrido desde el código hasta el contenedor.

Infraestructura simple, resultado visible.

Esta aplicación se ejecuta dentro de una máquina virtual ARM64. Coolify construye la imagen, inicia el contenedor y conecta el servicio con su proxy inverso.

Sistema
Ubuntu Server 22.04 LTS
Plataforma
Coolify Self-Hosted
Ejecución
Docker + Nginx
